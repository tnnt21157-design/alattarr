# محمص وبن العطار - متجر إلكتروني

موقع متجر كامل بـ Flask مع قاعدة بيانات SQLite ولوحة تحكم.

## المميزات

- قاعدة بيانات SQLite (المنتجات والأقسام قابلة للتعديل)
- لوحة أدمن كاملة: إضافة / تعديل / حذف / تفعيل-تعطيل المنتجات
- إدارة عروض العطور
- سلة مشتريات مع كميات وحذف
- إرسال الطلب عبر واتساب
- تصميم عربي متجاوب (RTL)

## بيانات الأدمن

- **المستخدم:** YOUSEAF
- **كلمة المرور:** 0788522

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح: http://127.0.0.1:5000

## الرفع على Render (الطريقة الصحيحة)

1. ارفع المشروع على GitHub (مستودع جديد)
2. ادخل إلى [render.com](https://render.com) وسجّل دخول
3. New → Web Service
4. اربط مستودع GitHub
5. الإعدادات:
   - **Runtime:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
6. اضغط Create Web Service

أو استخدم ملف `render.yaml` الموجود في المشروع (Blueprint).

> ملاحظة: على الخطة المجانية، قاعدة SQLite تُعاد عند إعادة التشغيل. للمنتجات الثابتة هذا مقبول، ولو حابب بيانات دائمة استخدم PostgreSQL لاحقاً.
